# Tutorial Video Plan

One walkthrough video per feature area. Each video demonstrates the sub-actions listed
below in the context of a real task (e.g. "ring up a sale"), rather than as an isolated
feature tour.

1. **Making a Sale (POS)** — search/scan products, add to cart, apply/remove a discount,
   select or add a customer, choose a payment method (incl. split payment), complete the
   sale and view/print the receipt, redeem a loyalty reward, hold and recall a sale,
   process a return/refund, log a missing product, handle an online order, browse
   transaction history.
2. **Managing Inventory** — add a product / add a stock batch, run a stock audit, transfer
   stock between stores, import/export via CSV, print barcode labels, manage suppliers,
   view the stock ledger, view a product's detail/batch/history.
3. **Prescriptions** (pharmacy stores only) — create a prescription, search/filter by
   status or priority, view and dispense a prescription.
4. **Managing Customers** — add/edit/delete a customer, view profile and credit balance,
   record a payment, set up loyalty tiers and redeem rewards, view customer activity.
5. **Procurement (Purchase Orders)** — create and edit a purchase order, receive stock
   against a PO, export a PO as PDF, track requested products, add a supplier.
6. **Expenses** — add an expense, view expense history.
7. **Reports & Analytics** — Daily Close, Operational Reports, Analytics & Insights
   (sales, P&L, stock, customers, staff).
8. **Activity Log** — browsing the full audit trail.
9. **Settings** — appearance, security, business info/branches, staff management, roles
   & permissions, payment/receipt/register config, product units/categories, alerts,
   data & sync/backup, billing, factory reset.

Note: Activity Log and Reports could be merged into a single "Reports & Activity" video
if a shorter series is preferred.
